# 复读插件

这是一个基于 MaiMessages 框架和 SnowLuma / OneBot 接口开发的复读机插件。它可以检测群聊中连续重复的消息，并自动进行复读，为你的群聊增添更多乐趣。

✨ 主要功能
- **智能复读**：自动检测群聊中连续出现多次（默认 3 次）相同的文本消息，即触发复读。
- **非重复复读**：同一段连续刷屏只会复读一次，触发后清空计数窗口并抑制同一条文本，直到出现不同的消息后才会对新的重复段再次复读，避免长队列下的拖尾复读与无限循环。
- **状态隔离**：复读抑制状态按群/会话（stream_id）独立保存，不同群出现相同文本互不影响。
- **媒体与占位符过滤防护**：
  - 自动过滤图片、表情包等媒体格式消息；
  - 深度识别框架层媒体占位符（如 `[表情包]`、`[图片]`、`[语音]`、`[CQ:...]`、`[QQ表情:...]`、`[未知表情...]` 等），防止将降级占位文本误当真实群友发言复读发入群聊；
  - 遇到媒体消息或通知时自动清空当前会话计数窗口，打断文本复读链，避免前后无关文本误触复读。
- **通知事件过滤**：自动忽略“戳一戳”、禁言等非聊天消息，确保复读队列的干净。

🛠️ 安装与配置
1. 安装插件
将 repeat_plugin 文件夹放置在你的插件目录下。

2. 配置参数（config.toml）
```toml
[plugin]
config_version = "1.0.0"
enabled = true

[repeat]
debug_mode = false
trigger_count = 3
repeat_probability = 0.8 # 复读概率 (0~1)
skip_probability = 0.1   # 完全不复读的概率 (0~1)
```

📝 使用说明
插件安装并正确配置后，无需额外操作。

当群内出现连续三条完全相同的文本消息时，机器人会自动发送该消息进行复读。例如：

| 消息发送者 | 消息内容 |
|---|---|
| 群成员 A | 哈哈哈哈 |
| 群成员 B | 哈哈哈哈 |
| 群成员 C | 哈哈哈哈 |
| 机器人 | 哈哈哈哈 |
